TITLE: Neural Compute Convergence: Heterogeneous Scheduling Across Mobile NPUs and Discrete Edge GPUs
AUTHORS: Qualcomm AI Research & Vivo OriginOS Systems Laboratory
DATE: September 2026

ABSTRACT:
As mobile system-on-chips (SoCs) cross the 70 TOPS threshold, the operational paradigm of edge artificial intelligence shifts from cloud offloading to hierarchical on-device execution. This paper investigates the collaborative inference topology between the Qualcomm Snapdragon 8 Elite (SM8850) Hexagon Tensor Processor (HTP V79/V81) and discrete mobile GPUs (NVIDIA GeForce RTX 2050 Ampere). Through unified w4a16 weight-activation quantization and asynchronous inter-process communication (IPC) piggybacked on vendor-native synchronization suites (Office Kit), we demonstrate a 3.4x reduction in total end-to-end task latency while maintaining zero cloud data egress.

1. INTRODUCTION
Contemporary agentic workflows require continuous sensory ingestion (audio streams, optical character recognition, and accessibility graph inspection). Cloud-mediated pipelines introduce unacceptable latency (3.5–6.2s) and catastrophic data leakage. Conversely, mobile-only execution faces strict thermal envelopes during extended context ingestion exceeding 8,192 tokens. We propose a two-tier symbiotic architecture wherein the mobile NPU governs real-time voice interaction and sensory triage, while the desktop GPU acts as an on-demand extended context accelerator.

2. HARDWARE PROFILE & ARCHITECTURAL SPECS
2.1 Mobile NPU (Snapdragon 8 Elite)
The Hexagon NPU integrates a dedicated scalar execution unit, vector extensions (HVX), and a 4th-generation tensor accelerator (HTP). With 16GB of LPDDR5X memory operating at 10.7 Gbps, memory bandwidth reaches 76.8 GB/s. For a 4-billion parameter model quantized to w4a16 (int4 weights with fp16 activations), memory bandwidth saturation remains below 38%, permitting sustained token generation rates exceeding 32 tokens per second at 3.2W average system power.

2.2 Desktop GPU (NVIDIA GeForce RTX 2050 Laptop GPU)
Built on the Ampere GA107 architecture with 2048 CUDA cores and 4GB of GDDR6 VRAM across a 64-bit bus, the RTX 2050 provides ~112 GB/s peak bandwidth. Due to the 4096 MB VRAM ceiling, standard 8B fp16/int8 models trigger memory swapping to system RAM, degrading throughput to <4 tok/s. By deploying the identical 4B model quantized to Q4_K_M with FlashAttention-2, weight footprint occupies 2,480 MB, leaving 1,150 MB for an uncompressed 16,384-token KV-cache.

3. COGNITIVE HANDOFF & DATA PROTOCOL
The primary agent loop utilizes ReAct (Reasoning and Acting). When context tokens exceed the mobile thermal budget threshold (2,048 tokens), the agent formats an immutable TaskDescriptor JSON containing a cryptographic UUID, timestamp, task taxonomy, and raw payload. Rather than establishing independent network listeners prone to 802.11 beacon flooding at dense events, the payload is committed to the Android ClipboardManager. The vendor desktop suite (Office Kit) detects the clipboard delta, encrypts the buffer over TLS 1.3, and propagates it to the paired workstation within 180–320ms.

4. BENCHMARKS & EXPERIMENTAL RESULTS
Across 500 automated trials:
- Voice-to-first-token latency on mobile NPU: 1,420ms ± 85ms.
- Full screen OCR extraction and structured parsing: 280ms.
- Cross-device round-trip latency via Office Kit: 2,150ms for a 12,000-token payload.
- System battery drain during continuous 2-hour operation: 6.8% of 7000mAh capacity.

5. CONCLUSION
Heterogeneous dual-tier local execution represents the optimal architectural compromise between mobile immediacy and workstation reasoning depth, establishing a new benchmark for offline, private AI systems.
